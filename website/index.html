为什么是 ip-lookup

公共 IP 源很多，麻烦也很多。

每家格式不同、字段缺失、说挂就挂。ip-lookup 把这一切收敛成一个 Promise。

→

统一结果

无论哪个服务商命中，返回的都是同一个 IpLookupResult。字段用归一化工具兜底——数字当字符串来、字符串当数字来，都能安全转换。

const info = await lookup.lookupIp('8.8.8.8');
// { ip, country, isp, asn, latitude, … }
↻

自动轮转

网络错误、超时、解析失败——任一源失败自动落到下一个兼容源。成功之后游标前进，下次从不同服务商开始，天然分摊负载。

// ip.sb 挂了 → ipwhois → freeipapi …
const self = await lookup.lookupSelf();
!

安全标记

代理、VPN、Tor 出口节点标记是查询结果的一等公民——不靠猜，直接读每个服务商的公开字段。

if (info.isProxy) {
  // 风控逻辑从这里开始
}

内置服务商

八个源，按需轮转。

每个服务商声明自己的能力：能否查本机 IP、能否查指定 IP、响应是 JSON 还是文本。插件只调用兼容的源。

用法

两行代码，一个 Promise。

查本机、查指定 IP、处理全部失败——覆盖三个核心场景。

import { createIpLookupPlugin } from '@chaeco/ip-lookup';

const lookup = createIpLookupPlugin();

// 查询当前公网 IP 信息
const self = await lookup.lookupSelf();
console.log(self.ip, self.country, self.isp);
// → 203.0.113.7  China  China Telecom
// 查询指定 IP —— 例如风控 / 审计场景
const info = await lookup.lookupIp('8.8.8.8');

console.log(info.countryCode, info.asn);
// → US  15169

// 代理 / VPN / Tor 标记
if (info.isProxy || info.isTor) {
  // 命中异常流量
}
import { IpLookupError, createIpLookupPlugin } from '@chaeco/ip-lookup';

try {
  const result = await lookup.lookupSelf();
} catch (error) {
  if (error instanceof IpLookupError) {
    // 每个源失败的原因都保留
    console.error('All providers failed:', error.reasons);
  }
}

扩展

内置源不够？写一个 Provider 即可。

实现 5 个字段的接口，你的数据源就和内置源一样参与轮转。

import { createIpLookupPlugin } from '@chaeco/ip-lookup';
import type { IpLookupProvider } from '@chaeco/ip-lookup';

const myProvider: IpLookupProvider = {
  name: 'my-provider',
  modes: ['self', 'ip'],        // 支持的能力
  responseType: 'json',           // json | text
  buildUrl: (ctx) => `https://api.example.com/${ctx.ip ?? ''}`,
  parse: (raw) => {               // 归一化到统一结果
    const data = raw as Record<string, unknown>;
    return { ip: String(data.ip ?? ''), country: String(data.country ?? ''), provider: 'my-provider', raw };
  },
};

const lookup = createIpLookupPlugin({ providers: [myProvider] });
